三种布尔运算（数学讲解）

圆柱（A）与方管（B）—— 集合论视角：对一个三维空间里的点 p，三种运算就是三种"归属规则"。方管按空心管壳参与并集/交集（交集=管壁框架）；差集按方管外形整体挖孔。
一、集合定义与截面示意（俯视）

① 原始：圆柱 + 方管（空心）

A、B 两个元件叠放
绿色=圆柱 A　紫色=方管 B（管腔中空）
两个元件各自独立存在，执行布尔前先选中它们。

② 并集 A∪B

A∪B = { p │ p∈A 或 p∈B }
两个体合为一个整体：圆柱保留，空心管也保留（伸出部分为管壁、管腔中空）。
贯穿时效果：圆柱 + 伸出圆柱外的空心管段。

③ 交集 A∩B

A∩B = { p │ p∈A 且 p∈B }
只保留两个体重叠的部分：空心管的管壁在圆柱体内的那一段，管腔中空。
贯穿时效果：一个空心方管框架（不是实心块）。

④ 差集 A−B（挖孔）

A−B = { p │ p∈A 且 p∉B }
圆柱减去方管覆盖的空间：圆柱上挖出贯穿方孔（软件按方管外形整体挖孔，方管删除）。
贯穿时效果：圆柱带贯穿方孔——这就是您之前验收的"中空"效果。
二、3D 实际效果（可拖动旋转查看）

① 原始叠加（圆柱 A + 方管 B 贯穿）

② 并集 A∪B：圆柱 + 空心管伸出段（管腔中空）

③ 交集 A∩B：只留管壁框架（空心）

④ 差集 A−B：圆柱挖方孔，方管消失

三、三种运算对照表（贯穿场景）
运算数学定义圆柱保留？方管保留？最终形状
并集 A∪B属于 A 或属于 B 的点是（管腔处也保留）是（空心管壳伸出段）圆柱 + 伸出圆柱外的空心管段
交集 A∩B同时属于 A 和 B 的点否（只留管壁重叠带）否（管壁在圆柱内段）空心管壁框架（管腔中空）
差集 A−B属于 A 但不属于 B 的点是（挖出贯穿方孔）删除中空的圆柱（带方孔）
对应您遇到的问题：上次"贯穿时方管余在圆柱体外的部分还在"，正是并集（A∪B）的形态——管与圆柱合体，管伸出部分自然保留。
若您要的是"圆柱挖孔、方管消失"，应使用差集 A−B；若只要"管穿过圆柱的那一段"，应使用交集 A∩B。
三种运算已全部加入编辑器右键菜单：布尔差集(A−B挖孔)、布尔并集(A∪B合并)、布尔交集(A∩B共体)。
