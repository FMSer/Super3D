概述

SuperScript 是 Super3D 的脚本语言，语法简洁现代：支持变量、函数、数组、对象属性、事件监听与数学运算。脚本直接以 英文标识符 控制场景里的元件（元件名、函数名、变量名均使用英文）。

示例内置场景（小房子 house、风车 windmill、太阳系 solar system、弹跳球 bouncing ball、坦克大战 tank battle）全部使用英文元件名与英文脚本，可直接作为学习模板。

脚本怎么用

Super3D 有两类脚本入口，可以同时使用：

  1. 文档类脚本（.ss，推荐）：菜单【文件 → 文档类脚本…】或点击文档 Tab 的 .ss 标签打开整个工程的文档类编辑器； 它控制整个程序运行的整个周期（构造一次 → onEnterFrame 每帧 → 键盘事件全程）。
  2. 关键帧脚本：在时间轴关键帧（含空白关键帧）上右键【编辑此关键帧脚本…】挂独立脚本，播放进入该帧时执行一次。
  3. 桌面调试：菜单【控制】→【调试】；发布：菜单【文件】→【导出】生成 three.js 单文件 HTML（同一份脚本在桌面与导出网页中执行结果一致）。
  4. 脚本运行时的 trace() / print() 输出显示在底部【输出】面板；语法/运行错误显示在【编译器错误】面板并弹窗提示； hudText 赋值会在 3D 画面上方显示游戏文字。
元件名大小写敏感：脚本里写 ball.x，场景里元件名必须也是 ball（可在场景树里双击改名）。

文档类编辑器（.ss）

每个工程一个文档类文件：与 .s3d 同名、同目录（如 我的作品.s3d 对应 我的作品.ss），保存工程时同名 .ss 同时保存。编辑器功能：

  • 语法高亮：关键字蓝、类型紫、注释绿、字符串暗红、数字蓝。
  • 代码自动补全：输入 元件名.（如 mc.）后弹出该元件支持的属性候选 （x y z rx ry rz rotation rotationX/Y/Z sx sy sz s scaleX/Y/Z visible name parent type segments red green blue）， ↑↓ 选择、Enter/Tab 插入、Esc 关闭、双击插入；继续输入可过滤候选。
  • 回车自动缩进：回车继承上一行缩进；行尾 { 加一级；行首 } 减一级。
  • 格式化代码：Ctrl+Shift+F 或右键【格式化代码】——按代码缩进规范重排（package/class/function 同级缩进）。
  • 快捷键：Ctrl+A 全选、Ctrl+C/V/X 复制/粘贴/剪切、Ctrl+Z 撤销、Ctrl+S 保存（.ss 页保存时弹“另存为”）；右键菜单含 撤销/剪切/复制/粘贴/全选/格式化。
  • 文档 Tab：底部文档 Tab 显示 工程名.s3d | 工程名.ss；点 .ss 标签 × 可关闭（磁盘 .ss 保留，可经文件菜单重新打开）；鼠标悬停标签显示完整文件路径。
  • 输出与错误：trace()/print() 输出到【输出】面板；脚本错误显示在【编译器错误】面板并弹窗（含第几层第几帧与错误信息），播放/调试自动切换到此框。

关键帧脚本（Flash 式帧动作）

时间轴上的每个关键帧（含空白关键帧）都可以挂一段独立的 SuperScript，播放进入该帧时自动执行一次；不同关键帧可挂不同脚本。

  1. 在时间轴上把某关键帧（实心或空心菱形）上点右键 → 编辑此关键帧脚本…（或菜单【窗口 → 脚本窗口】编辑当前选中关键帧/空白关键帧的脚本）。
  2. 在弹出窗口写入 SuperScript（如 enemy.hp -= 10;），点【保存】。
  3. 播放时进入该帧即执行；时间轴上带橙色小三角的关键帧表示挂有脚本。
// 帧 20 的关键帧脚本：触发一次剧情
story.step = 1;
play();                       // 让时间轴继续播放
帧脚本与文档类脚本各自独立作用域，可通过元件属性（obj.x、hudText 等）相互交互；桌面调试与导出网页中的执行时机一致。 播放/调试执行关键帧脚本遇语法或运行错误时，会弹窗报错（含第几层第几帧与错误信息）并自动切换到【编译器错误】面板。

文档类脚本（Document Class，.ss）

整个工程可以像 Flash 一样创建一个“文档类”脚本（Flash 文档类风格：支持 package / import / class / extends 语法）。 文档类是独立文件：与 .s3d 同名、同目录（我的作品.s3d ↔ 我的作品.ss），保存工程时同名 .ss 同时保存。 文档类影响整个程序运行的整个周期：构造函数在播放开始时执行一次（初始化计分、血量、关卡状态等全局数据）； 此后 onEnterFrame / addEventListener 回调每帧执行，onKeyDown / onKeyUp 键盘事件全程生效—— 即使时间轴没有任何关键帧脚本也会持续运行。文档类中的其他函数被事件驱动或直接调用后才执行。

  1. 菜单【文件 → 文档类脚本…】（或点击文档 Tab 的 .ss 标签）打开文档类编辑器，首次打开自动填入模板 （super3d.Object3D 基类，替代 flash 的 MovieClip）。
  2. 按 Flash 文档类风格写入代码，Ctrl+S 保存（.ss 页保存时弹“另存为”选择位置）。
  3. 点 .ss 标签 × 可关闭编辑器（磁盘 .ss 文件保留，可经文件菜单重新打开）。
package {
    import super3d.Object3D;

    public class main extends Object3D {
        private var hp:int = 100;

        public function main() {
            // 构造函数：播放开始时执行一次
            score = 0;
        }

        public function onEnterFrame(e:Event):void {
            // 每帧执行
            ball.ry += 2;
        }

        public function onKeyDown(e:Event):void {
            // 键盘按下事件
            if (e.keyCode == Key.W) ball.x += 5;
        }
    }
}
文档类生命周期：构造一次（播放开始）→ onEnterFrame 每帧 → 键盘事件全程。编辑播放、调试（Super3DPlayer）、HTML 导出三通道语义一致。 文档类中加入 stop() 时：时间轴停止播放，但文档类相关代码与帧代码照常执行（Flash 语义）。 文档类中定义的函数可在主脚本中通过同名调用（导出网页中同一解释器内共享）。 trace()/print() 输出显示在底部【输出】面板；脚本语法或运行错误显示在【编译器错误】面板并弹窗提示。

全局函数 — print() / trace()

function print(text:*):void
function trace(...args):void

把文本输出到输出框（print 与 trace 等价，旧中文写法 输出() 仍兼容）。

print("Hello World!");            // 输出字符串
trace("score=" + score);          // 拼接变量
print(ball.x);                    // 输出元件属性值

全局函数 — sin() cos() tan() sqrt()

function sin(angleDeg:Number):Number
function cos(angleDeg:Number):Number
function tan(angleDeg:Number):Number
function sqrt(x:Number):Number

三角函数按角度（度）计算；而 Math.sin() 等按弧度计算，二者不同。它们用于让元件做圆周/波浪运动，如太阳系公转、弹跳球跳动。

ball.y = 1 + 4 * abs(sin(frame * 8));   // 弹跳：8 帧一个周期
mercury.x = 6 * cos(frame * 5);          // 公转 x 分量
mercury.z = 6 * sin(frame * 5);          // 公转 z 分量

全局函数 — abs() min() max() random()

function abs(x:Number):Number
function min(a:Number, b:Number):Number
function max(a:Number, b:Number):Number
function random():Number

abs 取绝对值；min/max 取较小/较大值；random 返回 0~1 之间的随机数。旧中文写法 绝对值()/最小()/最大()/随机() 仍兼容。

ball.y = abs(sin(frame * 8));            // 永远取正，形成跳动
target.x = (random() - 0.5) * 10;        // 随机落点 -5~5
speed = max(speed, 0.1);                 // 下限保护

全局函数 — play() stop() gotoFrame()

function play():void
function stop():void
function gotoFrame(f:Number):void

控制场景时间轴播放/停止/跳帧（对应旧中文 播放()/停止()/跳到帧()）。

if (score > 10) stop();      // 得分超过 10 停止动画
gotoFrame(0);                 // 回到第 0 帧重播

全局函数 — Number() int() String() Boolean()

function Number(value:*):Number
function int(value:*):int
function uint(value:*):uint
function String(value:*):String
function Boolean(value:*):Boolean

类型转换函数。

var n:Number = Number("3.5");   // 3.5
var i:int = int(3.9);           // 3
var s:String = String(score);   // "100"

类 — stage（舞台）

舞台对象，负责键盘事件与按键状态。

属性

属性类型说明
stage.keyCode（或 keyCode）Number最近一次键盘事件的键码

方法

stage.addEventListener(type:String, handler:Function):void

注册舞台事件监听，事件类型用 KeyboardEvent.KEY_DOWN / KeyboardEvent.KEY_UP / Event.ENTER_FRAME 常量，处理器传函数名。这是事件驱动写法，比在 onEnterFrame 里轮询 Key.isDown 更省、更顺滑。

stage.addEventListener(KeyboardEvent.KEY_DOWN, onKeyDown);
stage.addEventListener(KeyboardEvent.KEY_UP, onKeyUp);
function onKeyDown(e) { if (e == 87 || e == 38) mv = 1; }   // e 是键码
function onKeyUp(e)   { if (e == 87 || e == 38) mv = 0; }

事件与每帧执行

三种驱动方式（可同时使用）：

  1. onEnterFrame 函数：定义了 function onEnterFrame(e:Event):void { ... } 后，它每帧执行；顶层代码只在开始时执行一次。未定义函数的旧脚本则整段每帧执行。
  2. addEventListener 注册：stage.addEventListener(Event.ENTER_FRAME, myFunc) 注册每帧函数；KeyboardEvent.KEY_DOWN/KEY_UP 注册键盘事件。
  3. Key.isDown 轮询：在 onEnterFrame 里查询按键状态。
推荐游戏用事件驱动：键盘用 stage.addEventListener(KeyboardEvent.KEY_DOWN/KEY_UP, 函数)，回调参数 e 为键码；每帧逻辑放在 onEnterFrame 里。

示例 — 键盘小游戏

场景放一个球命名 player，一个立方体命名 target。方向键/WASD 移动 player，碰到 target 得分，target 随机跳走。

var speed:Number = 0.3;
var score:Number = 0;
function onEnterFrame(e:Event):void {
    if (Key.isDown(Key.LEFT)  || Key.isDown(Key.A)) player.x -= speed;
    if (Key.isDown(Key.RIGHT) || Key.isDown(Key.D)) player.x += speed;
    if (Key.isDown(Key.UP)    || Key.isDown(Key.W)) player.z -= speed;
    if (Key.isDown(Key.DOWN)  || Key.isDown(Key.S)) player.z += speed;
    player.ry += 2;
    var dx:Number = player.x - target.x;
    var dz:Number = player.z - target.z;
    if (Math.abs(dx) < 1 && Math.abs(dz) < 1) {
        score += 1;
        target.x = (Math.random() - 0.5) * 10;
        target.z = (Math.random() - 0.5) * 10;
        trace("score=" + score);
    }
}

示例 — 坦克大战（完整脚本）

内置示例「坦克大战」的完整脚本（英文标识符、键盘事件驱动）。元件：playerTank（含 playerBody/playerTurret/playerGun/playerTrackL/playerTrackR）、enemy1~3、bullet、enemyBullet、wall、obstacle1~4、ground。

var score = 0;
var hp = 100;
var en1 = 1; var en2 = 1; var en3 = 1;
var d1 = 1; var d2 = -1; var d3 = 1;
var ba = 0; var bx = 0; var bz = 0; var bd = 0;
var ea = 0; var ex = 0; var ez = 0; var ed = 0;
var cd = 0; var cde = 0; var over = 0;
var mv = 0; var tr = 0; var fk = 0;
function onKeyDown(e) {
    if (e == 65 || e == 37) tr = 1;
    if (e == 68 || e == 39) tr = -1;
    if (e == 87 || e == 38) mv = 1;
    if (e == 83 || e == 40) mv = -1;
    if (e == 32) fk = 1;
}
function onKeyUp(e) {
    if (e == 65 || e == 37) { if (tr == 1) tr = 0; }
    if (e == 68 || e == 39) { if (tr == -1) tr = 0; }
    if (e == 87 || e == 38) { if (mv == 1) mv = 0; }
    if (e == 83 || e == 40) { if (mv == -1) mv = 0; }
    if (e == 32) fk = 0;
}
stage.addEventListener(KeyboardEvent.KEY_DOWN, onKeyDown);
stage.addEventListener(KeyboardEvent.KEY_UP, onKeyUp);
function hitWall(x, z) {
    if (Math.abs(x) < 3.5 && Math.abs(z) < 3.5) return true;
    if (Math.abs(x + 10) < 1.5 && Math.abs(z + 10) < 1.5) return true;
    if (Math.abs(x - 10) < 1.5 && Math.abs(z - 10) < 1.5) return true;
    if (Math.abs(x + 10) < 1.5 && Math.abs(z - 12) < 1.5) return true;
    if (Math.abs(x - 10) < 1.5 && Math.abs(z + 12) < 1.5) return true;
    return false;
}
function playerFire() {
    ba = 1;
    bd = playerTank.ry;
    bx = playerTank.x - sin(bd) * 2.0;
    bz = playerTank.z - cos(bd) * 2.0;
    bullet.visible = true;
    bullet.ry = bd;
}
function onEnterFrame(e:Event) {
    if (over == 1) return;
    if (tr == 1) playerTank.ry = playerTank.ry + 3;
    if (tr == -1) playerTank.ry = playerTank.ry - 3;
    var sp = 0.15;
    var nx = playerTank.x;
    var nz = playerTank.z;
    if (mv == 1) { nx = playerTank.x - sin(playerTank.ry) * sp; nz = playerTank.z - cos(playerTank.ry) * sp; }
    if (mv == -1) { nx = playerTank.x + sin(playerTank.ry) * sp; nz = playerTank.z + cos(playerTank.ry) * sp; }
    if (!hitWall(nx, nz)) { playerTank.x = nx; playerTank.z = nz; }
    if (playerTank.x > 20) playerTank.x = 20;
    if (playerTank.x < -20) playerTank.x = -20;
    if (playerTank.z > 20) playerTank.z = 20;
    if (playerTank.z < -20) playerTank.z = -20;
    cd = cd - 1; if (cd < 0) cd = 0;
    if (fk == 1 && ba == 0 && cd == 0) { playerFire(); cd = 14; }
    if (ba == 1) {
        bx = bx - sin(bd) * 0.55;
        bz = bz - cos(bd) * 0.55;
        bullet.x = bx; bullet.z = bz;
        if (en1 == 1 && Math.abs(bx - enemy1.x) < 1.5 && Math.abs(bz - enemy1.z) < 1.5) { en1 = 0; enemy1.visible = false; enemy1Gun.visible = false; ba = 0; bullet.visible = false; score = score + 10; }
        if (en2 == 1 && Math.abs(bx - enemy2.x) < 1.5 && Math.abs(bz - enemy2.z) < 1.5) { en2 = 0; enemy2.visible = false; enemy2Gun.visible = false; ba = 0; bullet.visible = false; score = score + 10; }
        if (en3 == 1 && Math.abs(bx - enemy3.x) < 1.5 && Math.abs(bz - enemy3.z) < 1.5) { en3 = 0; enemy3.visible = false; enemy3Gun.visible = false; ba = 0; bullet.visible = false; score = score + 10; }
        if (hitWall(bx, bz) || Math.abs(bx) > 20 || Math.abs(bz) > 20) { ba = 0; bullet.visible = false; }
    }
    if (en1 == 1) { enemy1.x = enemy1.x + 0.07 * d1; if (enemy1.x > 15) d1 = -1; if (enemy1.x < -15) d1 = 1; }
    if (en2 == 1) { enemy2.x = enemy2.x + 0.06 * d2; if (enemy2.x > 15) d2 = -1; if (enemy2.x < -15) d2 = 1; }
    if (en3 == 1) { enemy3.x = enemy3.x + 0.065 * d3; if (enemy3.x > 15) d3 = -1; if (enemy3.x < -15) d3 = 1; }
    if (en1 == 1) { enemy1.ry = Math.atan2(enemy1.x - playerTank.x, enemy1.z - playerTank.z) * 180 / Math.PI; }
    if (en2 == 1) { enemy2.ry = Math.atan2(enemy2.x - playerTank.x, enemy2.z - playerTank.z) * 180 / Math.PI; }
    if (en3 == 1) { enemy3.ry = Math.atan2(enemy3.x - playerTank.x, enemy3.z - playerTank.z) * 180 / Math.PI; }
    cde = cde - 1; if (cde < 0) cde = 0;
    if (ea == 0 && cde == 0) {
        if (en1 == 1) { ea = 1; ed = enemy1.ry; ex = enemy1.x - sin(ed) * 2.0; ez = enemy1.z - cos(ed) * 2.0; enemyBullet.visible = true; enemyBullet.ry = ed; cde = 40; }
        else if (en2 == 1) { ea = 1; ed = enemy2.ry; ex = enemy2.x - sin(ed) * 2.0; ez = enemy2.z - cos(ed) * 2.0; enemyBullet.visible = true; enemyBullet.ry = ed; cde = 40; }
        else if (en3 == 1) { ea = 1; ed = enemy3.ry; ex = enemy3.x - sin(ed) * 2.0; ez = enemy3.z - cos(ed) * 2.0; enemyBullet.visible = true; enemyBullet.ry = ed; cde = 40; }
    }
    if (ea == 1) {
        ex = ex - sin(ed) * 0.5;
        ez = ez - cos(ed) * 0.5;
        enemyBullet.x = ex; enemyBullet.z = ez;
        if (Math.abs(ex - playerTank.x) < 1.5 && Math.abs(ez - playerTank.z) < 1.5) { ea = 0; enemyBullet.visible = false; hp = hp - 5; }
        if (hitWall(ex, ez) || Math.abs(ex) > 20 || Math.abs(ez) > 20) { ea = 0; enemyBullet.visible = false; }
    }
    if (hp <= 0) { over = 1; hudText = "Game Over! Score=" + score + " Click to restart"; }
    else if (en1 == 0 && en2 == 0 && en3 == 0) { over = 1; hudText = "Victory! All enemies destroyed Score=" + score + " Click to restart"; }
    else { hudText = "Tank Battle  HP=" + hp + "  Score=" + score + "   W/S move A/D turn Space fire"; }
}
